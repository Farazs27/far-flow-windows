## Documentation conflicts kept open

The model card/technical report support v3 Dutch while a broader NVIDIA checkpoint table used an inconsistent English label; prefer exact-checkpoint evidence, then test the actual conversion. Quantized ONNX CUDA support depends on graph/operators/dtypes and current runtime, so blanket prohibition/availability guidance is insufficient. Microsoft's single-file/self-contained and App Installer prompt descriptions disagree in scope; the selected deployment form must be tested. Published runner image manifests override a generic migration announcement.

These are resolved for planning by narrower statements and explicit test gates, not by pretending a website search measured Windows behavior. Only implementation on a Windows host can settle the remaining runtime questions.
